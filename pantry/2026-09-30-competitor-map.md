# Competitor map: LibreSecOps-Claude-Code

First full-research run, 2026-09-30. Star counts come from the GitHub API on 2026-09-30. Capability claims come from each source's own README or files, read on 2026-09-30. A `?` means we did not find the answer in the source, not that the answer is no.

## Product

- Name: LibreSecOps-Claude-Code, marketplace `libre-secops`, release 1.0.1 (plugin manifests at 1.0.0)
- Flagship: `threat-modeling` (the depth-complete plugin in the 0.2.0 entry of [CHANGELOG.md](../CHANGELOG.md))
- Our surfaces: 33 plugins in [`.claude-plugin/marketplace.json`](../.claude-plugin/marketplace.json): 32 domain plugins with 64 agents, 53 commands and 57 skills, plus the optional `libre-secops-hooks` plugin (session-start security profile, a confirmation before edits to `.env`, key and credentials files, and a local vulnerability pattern scan after each edit). Offensive-capable plugins (penetration-testing, red-team-operations, bug-bounty-methodology, vulnerability-scanning, malware-analysis, phishing simulation) are framed for authorized engagements, agreed scope and isolated labs only. Install paths: `/plugin marketplace add HermeticOrmus/LibreSecOps-Claude-Code`, the `claude plugin` CLI, or `./setup.sh`. No MCP servers, no evals. CI validates the marketplace and every plugin, then installs all of them into a clean config.
